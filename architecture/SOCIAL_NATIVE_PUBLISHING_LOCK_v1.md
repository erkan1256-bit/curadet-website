## Fundamental rule
Social media deliverables MUST be designed and validated for the actual native platform surface. A generic vertical file is not automatically an Instagram-native Story or Reel.

## Locked rules

1. **Instagram Native Reel and Story are separate output architectures.**
   - They may share source artwork and music, but each output is composed and validated for its own native UI and use case.
   - A Story file MUST NOT be treated as a Reel merely by renaming/reusing it, and vice versa.

2. **Master canvas is locked to 1080 × 1920 px (9:16)** for Instagram Story/Reel and the established vertical social master workflow.

3. **Safe-zone validation uses the real current phone/platform interface as the reference.**
   - Important text, song title, face, principal character/object/instrument, CURADET branding, platform line and web address must not be obscured by native interface controls.
   - Static remembered margins are not sufficient when the platform UI has changed; current target-platform validation takes precedence.

4. **Approved CURADET brand geometry is immutable unless the Owner explicitly changes the brand master.**
   - Single approved logo source: `CURADET_LOGO_ONAYLI_GORSEL_REFERANS_v1.png`.
   - Do not redraw, reinterpret or regenerate the logo.
   - Gold A remains in approved geometry and its interior remains empty.
   - Approved tagline: `MUSIC • RIGHTS • TECHNOLOGY`.

5. **Real music is mandatory in music-video deliverables.**
   - The actual selected audio file must be embedded/muxed into the delivered video.
   - A waveform, player graphic, music icon or visual simulation does NOT count as embedded music.
   - Audio presence, duration and synchronization must be technically checked before delivery.

6. **Story standard: 30 seconds.**
   - Use the strongest/most suitable verified section of the song.
   - The selected segment must be derived from the real music file, not guessed from title or memory.

7. **Reel standard: full song.**
   - Unless a later explicit campaign decision creates a separate short-form Reel variant, the locked standard remains the complete song with real audio embedded.

8. **Pixel-level visual control is mandatory before final delivery.**
   Validate at minimum: dimensions, crop, safe zones, typography, spelling, logo geometry, logo scale, footer/platform order, web address, alignment, visual artifacts, unintended clipping, composition and platform UI collision.

9. **NO PASS → NO FINAL DELIVERY.**
   - A file that has not passed the required visual/audio/native-platform controls is DRAFT/TEST, never FINAL.
   - Creation is not verification; export is not acceptance.

10. **A new locked decision invalidates older conflicting finals.**
    - After a new rule or approved correction is introduced, an older file that conflicts with it MUST NOT be supplied or represented as the current final.
    - It must be regenerated/revised, retested and versioned first.

11. **Locked short delivery format.**
    Final operational reporting uses the established CURADET status icons and remains concise:
    - 🔒 KİLİTLİ — binding rule/final accepted standard
    - 🔵 ÇALIŞIYOR — real work currently being executed
    - 🧪 TEST EDİLİYOR — actual validation/test in progress
    - ✅ TAMAMLANDI — required implementation and verification complete
    - ⚠️ RİSK / EKSİK — known deficiency/risk
    - ⛔ ENGEL — real blocker prevents progress
    - 🟠 OWNER GEREKLİ — genuine Owner-only action/decision
    - 🔄 GÜNCELLENDİ — verified new version of an existing locked source
    - 📌 KAYDEDİLDİ — source/version/evidence recorded

## Required native publishing gate
A social asset may be marked FINAL only after all applicable checks pass:

`LOCKED PRINCIPLES → APPROVED ASSETS → REAL AUDIO → NATIVE OUTPUT TYPE → 1080×1920 → SAFE-ZONE / CURRENT UI → PIXEL QC → AUDIO QC → DURATION QC → VERSION CHECK → FINAL`

If any required gate is missing or fails, status remains DRAFT/TEST/BLOCKED.
